# Vibe Scraper Chrome extension

This is a small Manifest V3 extension with a vanilla HTML/CSS/JS popup UI.

## Load it in Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select this `extension` directory.
5. Open a normal website, click the extension icon, and choose **Scrape active page**.

The popup reads links from the active tab and displays them as a starter result list. It is intentionally simple so workshop participants can add selectors, fields, and CSV export.
