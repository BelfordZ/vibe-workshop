# Vibe Coding Workshop

Small, self-contained browser automation examples:

- [`playwright/`](./playwright) — a Playwright scraper that writes links to CSV.
- [`extension/`](./extension) — a basic Manifest V3 Chrome extension with a popup UI.
- [`react/`](./react) — a minimal React + Vite app, deployed to GitHub Pages on pushes to `main`.

See [`scraping.md`](./scraping.md) for the workshop notes.
