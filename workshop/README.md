# Workshop materials

A 4½-hour hands-on workshop for dealership staff. Each participant leaves with one small automation they can run and explain.

- [Presentation](presentation.md): audience-facing Markdown slides separated by `---`. Read in a Markdown preview or adapt to your preferred slide tool.
- [Presenter notes](presenter-notes.md): slide-by-slide speaking cues, questions, transitions, and timing.
- [Before the workshop](prework.md): send to participants ahead of time.
- [Facilitator guide](facilitator.md): timing, checkpoints, and recovery plans.
- [Project template](PROJECT.template.md): a short structure for the AI to fill in from your workflow.
- [Prompt examples](prompts.md): start with the interview prompt, answer the AI's questions, and review the resulting `PROJECT.md` before building.

Participants build around their own workflows and approved inputs. Existing code examples remain in their own folders in the repository.
